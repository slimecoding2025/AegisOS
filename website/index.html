What AegisOS is

AegisOS is an independent Linux distribution for cybersecurity work: defensive monitoring, digital forensics, network analysis, reverse engineering and security education. It is a real, installable project, not a themed desktop.

It reuses mature technology instead of reinventing it: Debian packages, apt, live-build and XFCE. Its own parts are a tool manager, diagnostics, reversible hardening and a local dashboard.

What you get

Bootable live ISO

A hybrid amd64 image that boots under UEFI into a live XFCE desktop with the Aegis welcome guide. BIOS boot is not supported.

The aegis tool manager

Search, inspect, install and remove tools by name or by profile. It calls apt, it never replaces it, and it refuses packages that have no candidate.

A manifest as the single source of truth

One file lists every tool with category, tier, install method and verification status. Profiles, docs and the ISO package list are generated from it.

aegis doctor

Thirteen health checks (OS, kernel, apt, repositories, DNS, connectivity, disk, time, dependencies, manifest, broken packages) with exit codes 0, 1 and 2.

Reversible hardening

Optional sysctl hardening in one drop-in file. Apply, audit and revert were run on a booted image: revert restored the previous settings.

Security Center

A read-only dashboard of real system data: kernel, memory, disks, interfaces, firewall, updates, services and listening ports. It binds to 127.0.0.1 only.

aegis-net

Interfaces, routes, DNS, connections and listening sockets, read straight from the kernel.

Tested in the open

CI runs ShellCheck, pytest, manifest validation, package builds and a Debian 13 package-name check on every push.

The tool ecosystem

Tools are grouped into 18 categories and installed through 12 profiles. Where a tool is not in Debian 13, it is listed as an external install instead of guessing a package name.

networkwebosintforensicsblue-teamsocwirelessreverse-engineeringmalware-analysiscloudcontainersdevelopment

On Debian 13.7, 95 apt package names resolved and 13 did not (for example ghidra, zeek, radare2 and nikto); those 13 are marked external. Resolving a name does not prove the tool was installed and tested. License and homepage fields stay "unverified" until checked against an official source.

Verify your download

Compare the checksum with the value in SHA256SUMS. On Windows:

Get-FileHash .\AegisOS-0.1.0-amd64.iso -Algorithm SHA256

On Linux, in the folder with both files:

sha256sum -c SHA256SUMS

Run it

Create a virtual machine with UEFI firmware, 2 or more CPUs, 8 GB RAM for the live session, and attach the ISO. Choose "Live system" in the boot menu.

Authorized use only. Offensive-security tools are packaged for authorized testing and education. Use them only on systems you own or have written permission to test. AegisOS ships no malware, credential theft, persistence or automated attacks against third parties.
