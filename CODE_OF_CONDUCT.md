# Code of Conduct

AegisOS contributors and maintainers pledge to keep this project a respectful,
harassment-free space for everyone, regardless of experience level, background,
or identity.

## Expected behavior

- Be respectful and constructive. Critique code and ideas, not people.
- Assume good faith; ask clarifying questions before assuming bad intent.
- Accept feedback gracefully and give credit where it is due.

## Unacceptable behavior

- Harassment, insults, discrimination, or personal attacks.
- Publishing others' private information.
- Using project spaces to plan or request help with unauthorized access to
  systems you do not own or have permission to test.

## Enforcement

Report concerns privately to the maintainers using the contact in
`SECURITY.md`. Maintainers may remove content or restrict participation to
protect the community. This policy is adapted in spirit from the Contributor
Covenant; it is a short project-specific text, not a verbatim copy.
